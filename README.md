# El Vaso Glassware (v2)

Static single-page site for El Vaso Glassware: handmade glassware from upcycled bottles, made in Nairobi.

Plain HTML, CSS and JavaScript with no build step. Deployed with GitHub Pages from the `gh-pages` branch. After changing `main`, run `git push origin main:gh-pages` to publish.

All photos in `images/` come from El Vaso's own photo library.
